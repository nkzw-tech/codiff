# Unstructured Commits

## Purpose

Materialize a realistic set of weakly related notification-preferences changes as one current
review target.

## Target

```text
main -> feature/test-scenario
```

## Proves

- The shared harness supports current reviews whose commits do not form one clean narrative.
- Scenario-local patches can extend the canonical shared patch sequence without duplication.
- The current review can be evaluated without provider or review-history state.
